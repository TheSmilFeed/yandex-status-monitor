Что там по серверам Яндекса?

Мониторинг состояния инфраструктуры и цифровых сервисов

Для чего нужен сайт

Сайт помогает посмотреть доступность цифровых сервисов Московского Политеха и Яндекса, сравнить результаты проверок и найти записи о сбоях.

Это учебный проект Литвинова Ивана Александровича, студента группы 233-321 Московского Политеха, по дисциплине «Веб-аналитика». Сайт используется для изучения посещаемости, источников переходов и поведения посетителей.

Проект не является официальным сервисом Яндекса или Московского Политеха. Данные формируются на основе автоматических проверок и открытых источников.

Как устроен мониторинг

Cloudflare Worker выполняет HTTP-проверки по расписанию раз в пять минут. Результаты сохраняются в Supabase, затем сайт получает их через публичный API. Кнопка «Обновить» загружает сохранённые результаты, а не запускает проверку.

Как читать статусы

«Работает штатно» означает успешную HTTP-проверку адреса. HTTP 200–399 не гарантирует, что вход в аккаунт, отправка писем или оплата работают. Коды 401 и 403 могут означать ограничение автоматических запросов: для них показано «Нет данных».

Для сервисов Политеха инцидент создаётся после трёх неудачных проверок подряд. Для Яндекса HTTP-ошибки недостаточно, чтобы объявить массовый сбой: нужно внешнее подтверждение. Сейчас внешние источники не подключены.

Графики и ограничения

Каждая точка графика доступности — результат одной проверки. График времени ответа показывает длительность запроса. Промежутки без измерений не заполняются. Фильтры «24 часа», «7 дней» и «30 дней» применяются к полученной истории, которая может покрывать период не полностью.

Проверки выполняются из сети Cloudflare. Доступность с вашего устройства может отличаться. Результат старше 15 минут считается устаревшим. Все даты на сайте указаны по Москве.

Главная страница Яндекса пока не включена в мониторинг API. Для неё показывается «Нет данных».
