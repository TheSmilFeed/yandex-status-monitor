# Следующие этапы

1. Зарегистрировать опубликованный сайт в LiveInternet, получить официальный код, установить на все HTML-страницы и проверить поступление данных.
2. Собирать реальную посещаемость 1–2 недели; по заданию привлечь минимум 50 реальных пользователей. Подготовить отчёт ЛР3 по фактическим данным.
3. Подготовить ЛР1 и теоретическую часть ЛР3 во время сбора статистики.
4. Для ЛР4 подключить Sber Ads, для ЛР5 — MyTracker, после получения действительных кодов.
5. Добавить отдельную проверку главной страницы Яндекса в существующий backend после получения и проверки подлинного исходника. Карточка уже предусмотрена, статус пока «Нет данных».
6. Расширить API для полных периодов истории и однозначной связи закрытых инцидентов с сервисом. До этого интерфейс явно показывает ограничения выборки.
7. Перенести подлинный Worker в Git и проверить scheduled-запись, read-only fetch, SQL и RLS отдельно, без замены работающего production.
8. При необходимости подключить подтверждённые внешние статусы, новости и сведения о ЦОДах с источниками и временем актуальности.
